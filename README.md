# MARSNGOINC — Social Network Home Page

Landing page for the social network project — vibrant red, white & blue design, approved 2026-10-01.

**Live site (once GitHub Pages is enabled):** https://christianxconstantin.github.io/MARSNGOINC/

The page is a single static `index.html` (no build step). Edit the file, commit, and GitHub Pages republishes automatically.

To enable Pages: repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`.
